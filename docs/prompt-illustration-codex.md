# Prompt illustration pour Codex

Colle ce prompt dans Codex pour generer une illustration :

---

**Sujet :** [SUJET DE L'ARTICLE]

**Style :**
- Illustration editoriale geopolitique
- Fond fonce (bleu nuit #1a1a2e)
- Accent rouge (#e30613)
- Police : Georgia pour les titres
- Format : 1200x630px
- Pas de texte, pas de logo

**Ambiance :**
- Serieusement professionnel
- Tons bleus et or
- Style carte simplifiee ou infographie
- Donnees discretes et elegantes

**Exemples de sujets :**
- Carte d'Afrique avec zones de conflit
- Schema de flux diplomatiques
- Representation de donnees economiques
- Carte thematique par pays

---

Ou plus simplement, dans Codex tu peux demander :

> "Cree une illustration editoriale pour un article geopolitique sur [SUJET]. Style fonce, tons bleus et or, format 1200x630. Pas de texte."
